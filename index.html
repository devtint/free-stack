Ship real apps on free tiers

Plain guides to hosting, databases and bots for solo builders. Each one starts from an empty account and ends with something deployed, with the limits spelled out so nothing surprises you later.

What are you building?

Frontend and serverless functions on Vercel, data and login on Supabase.

  1. Put the code on GitHub with the Git guide.
  2. Create a project, a table and RLS policies with the Supabase guide.
  3. Deploy and add environment variables with the Vercel guide.
  4. Optional: add your domain using the Cloudflare guide.

A Python webhook bot on Render, with users stored in Supabase.

  1. Create the bot and run it locally with the Telegram bots guide.
  2. Deploy it as a webhook with the Render guide.
  3. Store users in Supabase.
  4. Make replies instant with the keep-alive guide.

A Python or Node API on Render, Postgres on Supabase, tests on GitHub Actions.

  1. Create the database with the Supabase guide.
  2. Deploy the API with the Render guide.
  3. Run tests before each deploy with GitHub Actions.
  4. Stop cold starts and pauses with the keep-alive guide.

No server at all. Pick whichever host you like.

  1. Plain HTML: publish from a repository with GitHub Pages.
  2. A built site (Vite, Astro): deploy on Vercel or as Workers static assets.
  3. Add a custom domain with the Cloudflare guide.
